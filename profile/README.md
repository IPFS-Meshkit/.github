# IPFS MeshKit

### Lightweight IPFS tooling for modern applications.

MeshKit is an open-source ecosystem that makes it easy to build applications on top of IPFS.

We provide lightweight SDKs, developer tools, MCP servers, and production-ready examples that help developers integrate decentralized storage into web, mobile, AI, and backend applications without dealing with unnecessary complexity.

## 📦 What is MeshKit?

MeshKit helps developers:

* 📁 Upload, retrieve, and pin content on IPFS
* 🌐 Connect to multiple Kubo nodes with automatic failover
* 🔑 Publish and resolve IPNS records
* 🤖 Build AI applications using the Model Context Protocol (MCP)
* 📱 Develop interoperable mobile and web applications
* 🔌 Build on open standards including IPFS, libp2p, and CBOR
